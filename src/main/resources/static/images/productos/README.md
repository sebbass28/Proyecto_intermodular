# Imágenes de Productos

Coloca aquí las imágenes de tus productos con estos nombres:

- `osito-daisy.jpg` - Imagen del osito Daisy
- `conejito-srosa.jpg` - Imagen del conejito rosa
- `elefante-francisca.jpg` - Imagen del elefante Francisca
- `leon-valiente.jpg` - Imagen del león valiente
- `pinguino-polar.jpg` - Imagen del pingüino polar
- `unicornio-magico.jpg` - Imagen del unicornio mágico

## Formato recomendado:

- **Tamaño**: 300x250 píxeles (o proporción similar)
- **Formato**: JPG, PNG, o WebP
- **Tamaño de archivo**: Menos de 500KB por imagen

## Cómo añadir imágenes:

1. Guarda tus imágenes en esta carpeta
2. Usa los nombres exactos especificados arriba
3. Reinicia la aplicación para ver los cambios
